# AI-Persnalized-new-feed-recommender

Project: AI System Specification - Personalized News Feed Recommender

This project is an academic assignment for the Introduction to Artificial Intelligence course. It analyzes a Personalized News Feed Recommender (similar to Twitter/X or TikTok) using the PEAS Framework, Task Environment Classification, Critical Analysis, and JSON-based structured representation. The objective is to demonstrate how AI systems can be formally specified and evaluated before implementation.
